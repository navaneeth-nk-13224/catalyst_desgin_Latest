# Build Figma Screen

Build a new screen or UI component in Figma using the ZCatalyst Design System.

## Instructions

1. Read `docs/rules.md` — all 21 rules must be followed
2. Follow the workflow in `.github/copilot-instructions.md`
3. Always import the Layout component and detach before building
4. Use ONLY ZCatalyst DS components — never hand-build buttons, tables, badges, pagination, etc.
5. Always use the Table DS component (Boxy/Stretch) — NEVER build custom tables
6. Always place Pagination DS component below every Table
7. All colors must use imported variables — no raw hex
8. All text must use imported text styles
